# Sunnah Meal Desktop App 🍽️

A modern desktop application for discovering and planning meals based on Sunnah foods mentioned in Islamic teachings.

## 📦 Download & Run

### Option 1: Download Executable (Windows)
1. Go to the `dist/SunnahMealApp-win32-x64/` folder
2. Download `SunnahMealApp.exe`
3. Double-click to run (no installation needed)

### Option 2: Run from Source
```bash
# Clone repository
git clone https://github.com/pu3anisfira-collab/sunnah-meal-app.git

# Install dependencies
npm install

# Start application
npm start

# Build executable
npm run build
